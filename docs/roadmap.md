# RepoGuard AI Roadmap

This roadmap reflects delivered behavior instead of historical version promises.

## Available now

- Recursive local scanner with `.gitignore` and YAML configuration support
- Terminal, JSON, and SARIF 2.1.0 output
- Secret, prompt injection, phantom Unicode, dangerous code, GitHub Actions, model loading, agent, and MCP rules
- Stable finding fingerprints and baseline-based incremental adoption
- Exact Git index scanning for reliable pre-commit checks
- Native composite GitHub Action using the bundled scanner
- CI on supported Node.js LTS versions and staged npm publishing through OIDC
- Auditable inline suppressions with required reasons and optional expiry policy
- Diff-aware scans against a Git base revision with `--changed-since`
- SARIF rule metadata mapped to OWASP GenAI, OWASP Agentic, GitHub, and OpenSSF guidance
- OpenSSF Scorecard, dependency review, and CycloneDX release evidence

## Next

- Diff-aware pull request annotations
- Monorepo configuration inheritance
- Community rule packs with signed metadata
- Lockfile policy checks and optional policy profiles

## Later

- Editor integrations over a stable machine-readable protocol
- Repository trend reports for new, fixed, and recurring findings
- Signed rule-pack distribution and verification
